
## use moco cli to develop and release workflow
- setup moco cli
  - download moco-cli from `/tools/moco-cli-1.0.0.tgz`
  - install moco cli
  - moco login
- run examples
  - git clone https://github.com/moco-workflow/
  - moco run
- build and release your first workflow
  - my first workflow
  - moco publish
  - moco run deployed

- create new wfspec
- publish new version (with my first workflow)
